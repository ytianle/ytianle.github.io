# Personal Blog

> A personal knowledge base, visual notebook, and long-term thinking archive.

This blog is automatically deployed with GitHub Actions and built with MkDocs Material.

It is not only a place to write my daily notes, but also a structured system for organizing knowledge, projects, and reflections over time.

---

## Why I Built This Blog

Memory disappears.

Ideas get lost in chats, temporary documents, screenshots, or unfinished drafts.

I wanted to organize my knowledge in a non-traditional way, not as a linear or purely sequential system.. The concept of [Digital Garden](https://maggieappleton.com/garden-history) inspired me a lot. I wanted to plant the seeds of knowledge but I want to grow a tree instead of a scattered garden of disconnected notes. I prefer organizing knowledge by concepts rather than by subjects.

Here are my blog principles:

- writing like teaching - the best way to review notes is output it well.
- fast knowledge preservation with scalability and indexing.
- long-term knowledge system but always beginner friendly.
- bloging existence to encourage endless knowledge pursuing.

It is my personal second brain.
